First release of **Taskbar Groups+**, a rewrite of tjackenpacken/taskbar-groups on .NET 10.

**Install:** run this in PowerShell, or download the zip below and unzip it into a folder you'll keep.

```powershell
irm https://raw.githubusercontent.com/winfrydd/TaskbarGroupsPlus/main/get.ps1 | iex
```

Requires the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) (x64). The installer offers to install it.

**Highlights**
- Fast, sharp, rounded Windows 11 style popup with keyboard control and a right-click menu
- Store apps, folders and documents; drag in from the Start menu; drag to reorder
- Names under icons, icon sizes, light/dark/custom background, live preview
- Per-program Run as administrator, arguments and start folder
- One-click updates from inside the app
- Reads the original app's groups, so existing pins keep working
- Many bugs from the original fixed (see the README)
